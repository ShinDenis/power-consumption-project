# ⚡ Household Power Consumption Forecasting

## Предсказание потребления электроэнергии в домохозяйстве.
- ### Динамические данные. Временной ряд.
- ### Применение нейросетей, модель LSTM.

---

## Описание проекта

Проект решает задачу прогнозирования **общей активной мощности** (`Global_active_power`) в отдельном домохозяйстве Со (фр. Sceaux) — французская коммуна, южный пригород Парижа. Используется классический датасет UCI с поминутными измерениями за 4 года.

## Основная модель — **двухслойный LSTM** с регуляризацией и расширенным набором инженерных признаков.

## Методология

### 1. Анализ данных (`Analysis.ipynb`)

#### Пропущенные значения
- Доля пропусков: **~1.25%** от общего датасета, но **3.7% в 2010 году**
- Пропуски одинаковы по всем признакам → единая природа (сбои оборудования)
- Обнаружены крупные пропуски: самый длинный — **7225 минут** (август 2010)
- Вывод: деградация измерительного оборудования, а не природные события

#### Стратегия импутации
Сравнивались три метода на RandomForestRegressor (MAE):
- Линейная интерполяция
- Сплайн-интерполяция (3-й порядок)
- **MSTL** — мультисезонная декомпозиция (суточный + недельный цикл) с последующей интерполяцией

**Победитель: MSTL** — сохраняет сезонность и тренд, минимальные ошибки на деградированных данных 2010 года.

#### Корреляционный анализ (Pearson + Spearman)
- `Global_intensity` — корреляция ≈ 1.0
- `Sub_metering_3` — наиболее информативный суб-счётчик (структурный, регулярный сигнал)
- `Global_reactive_power` — информативен на крупных масштабах, убран из финальных признаков
- `Voltage` — полезен на малых масштабах (перегрузки, просадки)

#### Выбросы
Выбросы (IQR-метод) не удалялись: они представляют реальные пики нагрузки (бойлер, духовка, обогреватель) и несут важную информацию.

### 2. Feature Engineering + Моделирование (`Final_model.ipynb`)

Признаки добавлялись итеративно, каждый шаг тестировался на LSTM:

| Шаг | Признаки | Модель |
|---|---|---|
| Baseline | Исходные 6 признаков + MSTL-импутация | `LSTM_MSTL_imputed` |
| +Calendar | `hour`, `is_weekend` | `MSTL_calendar` |
| +Cycle | `hour_sin`, `hour_cos` | `MSTL_calendar_cycle` |
| +Lags | Лаги 1,2,3,6,12,24,48ч для `Global_intensity` и `Sub_metering_3` | `MSTL_calendar_cycle_lags` |
| +Rolling | Скользящие среднее и std (6, 24, 48ч) | `MSTL_calendar_cycle_lags_roll` |
| Best selection | Отбор лучших признаков по Permutation Importance | `MSTL_best_features` |
| **Final** | Лучшие признаки + улучшенная архитектура LSTM | `Final_LSTM_model` |

#### Набор признаков:

- **Календарные** — учитывают время суток и выходные дни  
- **Исходные измерения** — базовые показатели интенсивности, субсчётчиков и напряжения  
- **Лаговые** — значения признаков с задержкой во времени для учёта прошлых состояний  
- **Скользящие статистики** — средние и стандартные отклонения по скользящему окну  
- **Скользящие статистики целевой переменной** — агрегированные характеристики целевого показателя за последние шаги

### 3. Архитектура финальной модели

```

  ↓
```

# Итог работы:
- ## В рамках проекта решена задача прогнозирования потребления электроэнергии в домохозяйстве на основе временного ряда с часовым разрешением.
- ## Получены высокие показатели метрик в условиях используемой технологии и масштаба предсказаний.
- ## Практическая применимость:
  ### Ошибка в **0.32 кВт** на горизонте одного часа — это уровень точности, достаточный для реальных бизнес-задач. Энергосбытовые компании могут использовать такой прогноз для балансировки нагрузки и оптимизации закупок на оптовом рынке (Пр: покупка энергии в дешёвые ночные часы вместо пиковых даёт прямую экономию). Управляющие компании и ЖКХ получают инструмент планирования мощности без избыточного резерва. В системах умного дома прогноз на следующий час позволяет автоматически переносить включение тяжёлых приборов — стиральной машины, бойлера — на выгодный тариф. Наконец, отклонение факта от прогноза служит сигналом аномалии: это применимо для раннего обнаружения неисправностей оборудования или нетипичного потребления.
